# v0.7 data scout — transition physics and commercial release safety

The search priority remains professional real-string material that can improve Legato, Portamento, Vibrato and Bow-change without contaminating a commercial checkpoint.

## Release pool policy

The release pipeline accepts a source only when both the data-rights record and the project registry mark it as commercially safe. High technical value is not enough.

Current useful release candidates remain the established permissive pool such as Iowa MIS, current Good-sounds CORA distribution, TinySOL, and specifically cleared sources such as Sanidha/Ghent where their exact terms and downloaded artifacts are preserved in provenance.

## High-value sources that remain blocked

- **ARME Virtuoso Strings** — technically attractive Q4/performance material, but the verified terms are non-commercial / ShareAlike; research only.
- **String Performance Dataset (SPD)** — valuable violin/cello bow/body/contact information, but no explicit commercial ML model-weight permission has been verified for this project.
- **MOSA / MUSC / URMP / EEP / QUARTET family research corpora** — useful for analysis, alignment or academic benchmarking, but excluded from commercial learned weights unless the rights owner gives an explicit grant.
- **Mixed-provenance vibrato collections** — software license does not automatically clear embedded performance recordings. Audio provenance must be audited independently.
- **Wikimedia vibrato example previously treated as permissive** — the inspected asset carries ShareAlike/GFDL terms; v0.7 changes it to release-blocked instead of assuming a simple CC-BY path.

## Why the custom session remains essential

Public permissive data is sufficient to bootstrap string timbre and some motion/scale behavior, but there is still no single verified free corpus that gives all four western strings, dry professional stems, aligned fast/normal/slow Legato and Portamento, controlled Vibrato depths/rates, Bow-change labels, Mandarin-ballad phrasing, and explicit commercial ML/model-weight rights.

Therefore the proprietary recording cue pack is not a fallback; it is the final targeted dataset for crossing the “good virtual instrument” to “difficult to distinguish from a recording” boundary.
