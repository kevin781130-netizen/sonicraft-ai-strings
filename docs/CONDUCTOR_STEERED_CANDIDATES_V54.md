# SONICRAFT v5.4 Conductor-Steered Candidate Generation

## Purpose

Move v5.3 Conductor Intent ahead of expensive Shadow Render.

A/B/C retain their existing Conservative / Balanced / Expressive identities, but each section nudges them toward locally relevant search directions.

## Bounded steering

Steering only nudges:
- Gesture Dynamics Energy
- Vibrato Depth
- Phrase Vibrato Rate
- Bow Pressure
- Transition Continuity / Duration
- existing deterministic Ensemble attack offset

It cannot change note identity, timing, pitch, articulation or D Original.

Dynamic targets are capped by each D-derived section Dynamic ceiling.

Straight/non-vibrato anchors are not forced into vibrato.

Bow Reserve metadata is recomputed after Bow Pressure changes.

## Progressive rendering

Some Section Characters have one low-value candidate deferred:
- Intro/Release/Resolution defer C
- Climax defers A

Build/Sustain render all A/B/C/D.

D always renders.

If the primary-set Audio margin is below 0.025, deferred candidates are immediately rendered and the local ranking is recomputed.

Only after this expansion can local ambiguity trigger the proven full-song fallback.

## Why this is safe

Candidate budgeting controls *when* evidence is purchased, not which evidence is legally available.

Downstream:
- Audio Judge remains objective rendered-audio authority.
- Global Coherence can reject locally good but globally discontinuous repairs.
- Conductor Lock can reject macro-character violations.
- Merged-vs-D full render remains mandatory.
