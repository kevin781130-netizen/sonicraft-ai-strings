# v1.7 MIT Source Scout — Open-Source Frontier Exit

## Absorbed
### Shortcut Models (MIT)
Use: training pattern only. A single network is conditioned on desired step size and trained with flow anchors plus bootstrapped larger jumps. Runtime gains 1/2/4/8-step capability without a second model.

### MeanFlow (MIT)
Use: one-step quality benchmark/reference. Its average-velocity/JVP objective is deliberately not duplicated in the consumer runtime. It remains a challenger if Shortcut cannot meet one-step string ABX.

### ONNX Runtime (MIT)
Use: deployment escape hatch. The project retains the reduced-operator / ORT-format / CUDA-plugin build path so framework bytes can eventually be attacked after trained model parity exists.

## Not added merely for novelty
Generic consistency/few-step repositories are not stacked together. Multiple sampling theories in the shipping runtime would violate the size/complexity goal. They must challenge the same student and win measurable gates first.
